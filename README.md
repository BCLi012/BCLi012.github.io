## 关于我

武汉大学经济与管理学院物流管理（供应链运营试验班）在读，研究平台供应链的定价、产能分配与信息披露，关注消费者策略行为下的机制设计。研究之外：长跑、摄影与音乐。

名字 Bruce 来自两个我反复回去看的人——李小龙（"Be water" 对我来说不是口号而是一种做事方法）与梁博（他对一首歌的耐心提醒我，深比广重要）。

## 技术

纯静态站点：**Jekyll** 构建、**GitHub Pages** 托管。没有数据库、没有服务器、没有后台，除 Jekyll 外零依赖（一个自托管的 4KB 搜索库，无前端框架）。

界面为黑白灰编辑排版风格，明暗双主题，采用暖中性灰阶（纸白 / 炭灰）。
