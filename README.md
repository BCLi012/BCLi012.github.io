# 静水深流 · 苹果风个人博客

一个极简苹果风格的个人博客站点：写代码，也写文字。

线上地址：**https://apple-style-blog.app.workbuddy.link/**

## 功能

- **首页** — 个人 bio、渐变标语、最新文章、栏目入口
- **文章列表 / 详情** — 卡片式列表，详情页 Markdown 渲染（标题、引用、代码块、表格、图片）
- **标签分类** — 标签云、按标签筛选、分类栏目（文艺 / 随笔 / 技术 / 读书 / 生活）
- **关于页面** — 自我介绍与站点说明
- **后台管理** — 登录后可发布、编辑、删除文章
- **登录认证** — 邮箱密码登录、邮箱验证码登录、邮箱验证注册、忘记密码重置
- **图片与附件** — 编辑器内直接上传，自动插入正文

## 技术栈

| 层 | 选型 |
|---|---|
| 页面 | 原生 HTML + CSS + JavaScript（无构建步骤，单页 hash 路由） |
| 样式 | 手写 CSS 设计系统，跟随系统深色模式，毛玻璃导航 |
| Markdown | marked + DOMPurify（渲染并消毒） |
| 数据 | WorkBuddy 云数据库（PostgreSQL，行级安全策略） |
| 文件 | WorkBuddy 云存储（图片 / 附件，签名链接） |
| 认证 | WorkBuddy 云端账号体系（邮箱 + 密码 / 验证码） |

## 目录结构

```
.
├── index.html   # 页面骨架、导航与页脚
├── style.css    # 设计系统与全部样式
└── app.js       # 云端接入、路由、各页面渲染与后台逻辑
```

## 本地运行

无需构建，起一个静态服务器即可：

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# 打开 http://localhost:8080
```

> 注意：文章浏览、登录与上传依赖云端服务，而云端服务只对已登记的应用域名开放访问来源校验。
> 因此本地预览只能看到页面骨架与样式，**请在线上域名下体验完整功能**。

## 数据结构

文章存储在云数据库的 `posts` 表中：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | bigint | 主键，自增 |
| `owner_id` | text | 作者标识，由数据库按登录身份自动填充 |
| `owner_name` | text | 展示用昵称 |
| `title` | text | 标题 |
| `summary` | text | 摘要 |
| `content` | text | 正文（Markdown） |
| `category` | text | 分类 |
| `tags` | text[] | 标签数组 |
| `status` | text | `published` / `draft` |
| `created_at` / `updated_at` | timestamptz | 时间戳 |

安全策略：已发布文章所有人可读，草稿仅作者可见；新增 / 修改 / 删除均限定为文章作者本人。

## 图片与附件

正文中的图片和附件以 `cloud:<存储路径>` 占位保存，页面渲染时批量换取有时效的访问链接再展示，
因此不会出现过期死链。

## 说明

`app.js` 中的 `publishableKey` 是应用的公开标识，本身不携带任何权限——服务端会校验请求来源域名，
只有登记过的应用域名才能访问数据，因此它可以安全地放在前端代码中。
